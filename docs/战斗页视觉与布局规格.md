# 战斗页 V1 布局规范（Android 横屏）

本文件是战斗页固定基准：**16:9 横屏，1920×1080 逻辑画布**。除非真机验证确认存在明显问题，不调整比例。仅覆盖无尽战斗页；不做关卡、商城、能量、倍速、生命值、Combo 条、底部卡牌栏或广告入口。

| 区域 | X / Y 范围 | 尺寸 |
| --- | --- | --- |
| 顶部状态栏 | x 0–1920, y 0–120 | 1920×120 |
| 出生槽 | x 45–195, y 350–830 | 150×480，完整竖向大槽 |
| Defender 区 | x 220–540, y 150–1030 | 320×880，2×5 |
| 战场 | x 570–1870, y 150–1030 | 1300×880，10×5 |

## 顶部状态栏

- Defender 区正左侧中部：出生槽（x 45–195、y 350–830），以一个完整长方形提取槽表现；图标位于中间偏上，数值位于下方，空时不显示假 Defender。
- 中央：`分数 58,642`，是唯一常驻大数字。
- 右上：设置 / 暂停入口；暂停只打开菜单，不是速度控制。

## 格子与 Lane

- Defender 格为 160×176；战场格为 130×176。五行中心严格对齐，左侧两个 Defender 格共同对应右侧同一整条 Lane。
- 战场格线轻、以石板/土地/草地等原创纹理表达，必须能看出敌人逐格左移，但不能像表格。
- 五条 Lane 使用轻微不同明暗的横向道路；主题为森林村庄门口的花园防线，不模仿 PVZ 草坪。

## 实体规范

- 植物：单格逻辑占位，主体约占 75% 高度；数值在头顶 6–12px，白字深描边。1024 及以上仅略缩字号。
- 敌人：1×1 仅占一个战场格，头顶为暗红 HP 背板与白色数值。
- 2×2 大怪：逻辑真跨两行两列，视觉脚底锚在整个矩形水平中心、底部约 85%；只显示一个共享 HP。两条 Lane 的弹道分别射向其上/下半身。
- 奖励球：直径约 45–55px，数值在球心；同格球视觉错开 20–30px，但不改变逻辑。
- Projectile：1 发 1 颗、2 发 2 颗、4+ 固定 4 颗；同类弹体连续间隔 40–70ms，弹体不显示伤害数字。同一路两格植物用 Lane 中心 ±10px 的视觉偏移。

## 结算反馈（后续实现）

每 Turn 目标时长 0.6–1 秒：移动/合成 → 全体起手 → 弹丸 → 敌人/奖励球结算 → 敌人左移一格 → 停住等待。合成 150–250ms；死亡 200–350ms。当前灰盒只固化布局与数据接口，尚未制作动画帧。

## 静态 PNG 接口

路径固定于 `src/ui/assets.ts`：植物 `plant_001.png` 至 `plant_1024.png`，两种普通敌人、一种大怪、奖励球 1/2/4/8、统一 Projectile、两种地块和出生槽。首轮均为透明背景 PNG；角色主体不要把数值/HP 烘焙进图中。
