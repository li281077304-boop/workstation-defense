# Archived asset contract

Historical assets remain in their existing paths for Git-history stability and
reference. They are **not approved for new runtime references**.

- `plants/`: plant-era Defender art
- `d-family/`: former D Family character art
- `characters/`: former character-reference art
- `backgrounds/battlefield_v0.png`: former rural battlefield art
- legacy projectile/effect paths: historical visual material

When approved Production replacements exist, runtime references must use only
`public/assets/production/**`. This setup does not move or delete historical
files.
